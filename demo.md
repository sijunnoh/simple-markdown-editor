# Welcome to Simple Markdown Editor

A **rich WYSIWYG** editor for VS Code with _real-time_ formatting.

## Features

- **Bold**, _Italic_, Strikethrough, `Inline Code`
- Headings (H1 - H5)
- Bullet and numbered lists
- Task lists with checkboxes
